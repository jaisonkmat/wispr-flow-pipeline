# Wispr Flow: the dictation pipeline

Interactive field guide to how Wispr Flow works, stage by stage, from the decision to invoke through text landing in the app.

**Live:** https://jaisonkmat.github.io/wispr-flow-pipeline/

Built from primary sources only: Wispr's engineering blog, their help center and WebSocket API docs, the Baseten case study, and SE Radio 703 with Sahaj Garg. Every claim links to where it came from. Where something is not publicly documented, the page says so rather than guessing.

## Editing

`index.html` is the whole site. Self-contained, no build step, no dependencies.

```bash
# edit index.html, then
git add -A && git commit -m "your message" && git push
```

GitHub Pages rebuilds in about a minute.
